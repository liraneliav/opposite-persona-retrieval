# Data Documentation

## Raw corpus

The raw Reddit ChangeMyView corpus is not stored in this repository. Download it from Zenodo:

https://zenodo.org/records/3778298

Place the raw CSV at:

```text
data/raw/comments_cmv.csv
```

Expected columns:

```text
comment_id, author, comment_text, topic_title, thread_id, delta
```

## Final repositories

The repository includes the final balanced persona repositories used in the experiments:

```text
data/final_repositories/BLM_final_300_150pro_150anti_gpt.csv
data/final_repositories/guns_final_300_150pro_150anti_gpt.csv
data/final_repositories/same_sex_marriage_final_300_150pro_150anti_gpt.csv
```

Each topic repository contains 300 records: 150 pro and 150 anti.

## Intermediate files

Intermediate files are intentionally excluded to reduce repository size. They can be regenerated by running the notebooks in `dataset_construction/`.
